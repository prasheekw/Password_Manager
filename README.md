# Password Manager

A simple command-line Password Manager built with Python.

I have build the project allows users to store, view, and search website credentials using a text file for persistent storage.

## Features

* Add website credentials
* Store website, username, and password information
* Display all saved credentials
* Search credentials by website name
* Menu-driven interface
* Persistent storage using a text file

## Technologies Used

* Python
* File Handling
* Functions
* Loops
* Dictionaries
* Exception Handling

## How It Works

Credentials are stored inside a text file named `PasswordFile.txt`.

Each entry contains:

* Website
* Username
* Password

The program provides a menu where users can:

1. Add Credentials
2. Search Credentials
3. Display Credentials
4. Exit

## Run the Project

```bash
python password_manager.py
```

## Example Menu

```text
0. Exit
1. Add Credential
2. Search Credential
3. Display Credentials
```
